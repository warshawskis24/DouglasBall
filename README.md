# douglasball.com

Website of Douglas Ball, Canadian industrial designer. Static site served by GitHub Pages at https://douglasball.com.

- `index.html` is the built homepage (formerly `home.html` on the old host).
- `assets/` holds styles, scripts, images, audio and video.
- `CNAME`, `robots.txt` and `sitemap.xml` support the custom domain and search engines.

The original Gulp/Webpack source (`src/`, `config/`, `package.json`) is kept offline in the DouglasBall project folder.
